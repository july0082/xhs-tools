# 小红书关键词挖掘

从种子关键词出发，抓取小红书搜索框的联想词，做二级扩展，并基于联想排序计算相对热度，最终产出可用的关键词包与看板。

## 何时使用

- 用户给出若干种子关键词，想拿到小红书上一共有哪些搜索联想词
- 需要把关键词按热度排序、筛出值得做的词
- 需要导出一份能直接上传到投放平台的关键词包（CSV）
- 已有词库，想追加新种子词继续扩展

## 能力边界（先判断，别给用户错期待）

| 需求 | 能否做到 |
|---|---|
| 搜索联想词（下拉词） | ✅ 无需登录即可采集 |
| 二级扩展词（对下拉词再联想） | ✅ |
| 相对热度排序 | ✅ 基于联想接口的返回顺序计算 |
| 搜索结果页的笔记列表、点赞收藏数 | ❌ 未登录会被风控拦截（`error_code=300012`），移动端 UA 亦不可行 |
| 官方月搜索量 | ❌ 只能登录聚光平台（ad.xiaohongshu.com）用「关键词规划工具」查，属人工操作 |

若用户明确要「真实搜索量」，直接说明需要登录聚光，不要用相对热度冒充绝对数值。

## 环境检查

脚本依赖 `playwright` 与 `openpyxl`，并需要本机装有 Chrome。运行前先确认用哪个 Python：

```bash
python -c "import playwright, openpyxl; print('ok')"
```

失败时换一个解释器再试（Windows 上常见情况是多个 Python 并存）：

```bash
"/c/Program Files/Python312/python.exe" -c "import playwright, openpyxl; print('ok')"
```

两个都失败则安装：`pip install playwright openpyxl && playwright install chromium`。

下文命令中的 `PY` 指代这个可用的解释器。

## 三步流程

工作目录默认 `./xhs_keywords`，所有中间数据存其中的 `data.json`，可反复增量追加。

### 1. 采集

```bash
$PY scripts/miner.py "deepseek" "codex" "Claude" "muse" --workdir ./xhs_keywords
```

- 有头模式运行（会弹出 Chrome 窗口），比无头更不易触发风控，不建议加 `--headless`
- 会自动关闭可能出现的登录弹窗，不需要登录账号
- 每个种子词先逐字/关键前缀试探，再对每个一级词联想一次，同时产出二级词和排序数据
- 时间成本约为「一级词数量 × 4 秒」，百来个一级词约 6~8 分钟。命令耗时较长，用后台方式运行并等待完成通知
- 已采过的种子词会自动跳过；要重采先删掉 `data.json`

### 2. 算热度

```bash
$PY scripts/analyze.py --workdir ./xhs_keywords
```

输出每个词的 `heat`（联想热度）、`rel`（相关度）、`score`（综合推荐分）与 `grade`（S/A/B/C/D 梯队）。

### 3. 导出

```bash
$PY scripts/export.py --workdir ./xhs_keywords
```

产出到 `./xhs_keywords/outputs/`：

| 文件 | 说明 |
|---|---|
| `小红书关键词明细.xlsx` | 7 个 sheet：总表 / 按种子汇总 / 核心下拉 / 前缀扩散 / 二级扩展 / 热度排行 / 指标说明 |
| `关键词包_精选.csv` | 仅 S/A 档，单列纯词，可直接上传投放平台 |
| `关键词包_全部.csv` | 全量单列纯词 |
| `关键词数据_带指标.csv` | 全字段，供导入 BI 再加工 |
| `小红书关键词看板.html` | 交互式看板：Top50 条形榜、梯队色标、过滤与按热度排序 |

CSV 均为 UTF-8 with BOM（Excel 双击不乱码，主流广告平台可直接识别），每行一个词、无表头。

完成后用 `present_files` 呈现看板与 Excel，并简述本次新增的种子词、词量、S 档亮点。

## 交付时必须说清的两件事

1. **热度是相对值**：由联想接口的返回排序推算，反映词在搜索联想网络中的活跃度，不是官方搜索量。同批词内横向比较可靠，绝对值不可当真实搜索量。
2. **英文短词有噪音**：如 `muse` 会联想出「木薯糖水」、`codex` 会联想出「cod乙女系列」。这类词已通过相关度衰减压分，分析时优先看「核心下拉词」和 S/A 档，不要把前缀扩散词当结论。

## 增量维护

- 追加新种子词：直接再跑一次 `miner.py`，老词不会重采、不会覆盖
- 全量重来：删除 `xhs_keywords/data.json` 后重跑
- 只想改指标口径：改 `analyze.py` 后重跑 analyze 和 export，无需重新采集

## 故障处理

| 现象 | 原因与对策 |
|---|---|
| 提示「未找到搜索框」 | 页面被风控或改版。让用户手动打开 www.xiaohongshu.com 确认可访问；必要时删掉 `xhs_keywords/xhs_profile` 重建浏览器配置 |
| 大批词返回 0 | 输入频率过快。改动 `miner.py` 中 `suggest()` 的 `random.uniform(700,1300)` 加大间隔 |
| 含空格的词采不到 | 已处理 `%20`/`+` 两种编码与大小写；若仍失败，检查该词是否含特殊符号 |
| Excel 保存报 PermissionError | 同名文件正被 Excel/WPS 打开，让用户关闭后重跑，或换 `--out` 目录 |

指标细节与设计取舍见 `references/methodology.md`。改动指标口径前先读它。
